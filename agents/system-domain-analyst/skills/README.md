# Skills — System & Domain Analyst

## Core skills

### 1. codebase-map
Analyze source code to produce module map, key flows, technical debt hotspots, and natural extension points.

### 2. architecture-analysis
Describe high-level architecture, system boundaries, integration points, quality attributes (performance, offline, security, scalability) and major technical risks.

### 3. domain-modeling
Reconstruct or refine the domain model: core entities, relationships, business rules, and ubiquitous language.

### 4. process-mapping
Map real AS-IS business processes (steps, actors, systems, decisions, exceptions).

### 5. usage-analysis
Analyze logs, metrics and data samples to show actual usage patterns, drop-offs, dead features and quantitative pain.
