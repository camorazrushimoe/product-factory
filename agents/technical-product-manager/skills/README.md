# Skills — Technical Product Manager

Basic skill set for this role.

## Core skills

### 1. intake-normalize
Accept any raw business request (email, ticket, message, document).  
Clean it, extract entities, produce a structured Intake object and first Problem Hypothesis.

### 2. classify-and-route
Classify the request type (modernization, new capability, pain-driven, efficiency, compliance…) and recommend the appropriate depth / pipeline.

### 3. collect-constraints
Gather and maintain the full list of hard and soft constraints from all sources (system, business, people, regulatory).

### 4. shape-solutions
Given framed problems + constraints + system understanding, produce 2–4 distinct solution directions with clear trade-offs, effort/risk, and recommended sequencing.

### 5. write-product-spec
Produce a complete Product Specification using the standard template (Problem, Goals & Metrics, Scope, Solution Direction, Requirements, Constraints, Open Questions…).

### 6. manage-wiki
Own the project LLM Wiki: create/update pages, keep links and synthesis current, record provenance, handle contradictions.

### 7. drive-pipeline
Orchestrate collaboration with Researcher, System Analyst and Reviewer. Decide when to go deeper and when the Spec is ready for final review.
