# Skills — Product Researcher

## Core skills

### 1. problem-framing
Turn stated requests and observations into clear, evidence-based Problem Statements using JTBD and root-cause thinking.

### 2. synthesize-human-insights
Process meeting notes, interview transcripts and observations. Extract stated vs latent needs, tensions, language, and political signals.

### 3. support-pain-analysis
Analyze support tickets / complaints: find patterns, frequency, severity, workarounds, and which user segments suffer most.

### 4. opportunity-discovery
Identify and rank opportunities (not just problems). Estimate potential value and learning for each.

### 5. challenge-surface-requests
Actively question the first version of the request. Surface what people are really trying to achieve.
